Channel HQ

A private analytics tool for the owner's own YouTube channels.

Channel HQ is a personal, locally running application used by one creator to analyze the performance of their own YouTube channels (views, watch time, retention, traffic sources, comments) and to plan better videos. It is not offered to the public, has no user accounts and cannot be used by anyone other than its owner.

The application accesses the owner's YouTube data read-only through the YouTube Data API, YouTube Analytics API and YouTube Reporting API, after the owner signs in with Google. Data is stored only on the owner's own computer.
