Privacy Policy

Channel HQ · last updated October 24, 2026

Who this applies to

Channel HQ is a private, locally running tool used only by its owner to analyze the owner's own YouTube channels. There are no other users.

What data is accessed

With the owner's consent (Google sign-in), Channel HQ requests read-only access to:

  • YouTube account data (youtube.readonly): channel and video metadata and public statistics,
  • YouTube Analytics (yt-analytics.readonly, yt-analytics-monetary.readonly): views, watch time, retention, traffic sources, audience and estimated revenue reports for the owner's channels.

Channel HQ never uploads, edits or deletes anything on YouTube.

How data is used and stored

  • Data is used only to show the owner analytics about their own channels and to help plan their own videos.
  • Data and access tokens are stored only on the owner's own computer (and the owner's private backups). There is no server and no database operated by a third party.
  • The owner may use an AI assistant (Anthropic Claude) running on the owner's computer to analyze this data; such analysis is performed only for the owner.
  • Data is not sold, shared with advertisers, or transferred to anyone else.

Google API Services User Data Policy

Channel HQ's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Channel HQ also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

The owner can delete the local data at any time. Access can be revoked at any time at myaccount.google.com/permissions, after which Channel HQ can no longer access YouTube data.
